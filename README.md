##🧠 Predicting Customer Conversions with Linear Regression
This project demonstrates how to use Multiple Linear Regression to predict customer conversion rates from marketing campaign data. Built for beginners but with real-world structure and insights.

📊 Dataset
Realistic marketing data including:

Social Media Spend

Email Campaign Spend

Mobile Traffic %

Weekend Campaign Indicator

Conversion Rate (Target)

🛠️ Tools Used
Python

Pandas

Scikit-Learn

Matplotlib & Seaborn (for visuals)

🚀 What You’ll Learn
How to clean and prepare data

How to build a regression model

How to evaluate model performance (R², RMSE)

How to make predictions using new campaign data

How to identify the most impactful features

🎯 Goal
Help marketing teams predict future conversions, allocate budget smartly, and focus on high-impact channels.
